# PCBuilder — конфигуратор ПК

Статический сайт без сборки и зависимостей. Открой `index.html` в браузере — всё работает локально.

## Что есть

- **499 позиций** в 8 категориях: процессоры (27), матплаты (110), видеокарты (167), ОЗУ (84), накопители (18), охлаждение (14), БП (64), корпуса (15).
- **Картинка у каждой позиции**: SVG-иллюстрации генерируются локально (`images.js`) с учётом бренда, модели, числа вентиляторов, объёма памяти и т.д. Внешние загрузки не нужны.
- **Кнопка «🛒 Купить»** у товара и в панели сборки: открывает окно с магазинами — DNS, Ситилинк, М.Видео, Яндекс Маркет, Эльдорадо. Ссылка ведёт на страницу поиска этого товара в магазине (открывается в новой вкладке).
- Поиск по названию/характеристикам, фильтр по бренду и цене, 4 варианта сортировки.
- Сборка: по одному компоненту на категорию, клик по карточке добавляет/убирает.
- Проверка совместимости: сокет CPU↔плата, тип ОЗУ, сокет и мощность кулера, форм-фактор корпуса, длина видеокарты, рекомендуемая мощность БП.
- Сохранение сборки в `localStorage` (кнопки «Сохранить» / «Загрузить»).
- Реклама **Adsterra** уже подключена (сайт ID `6225335`, 4 активных ad unit'а).

## Реклама

Сейчас включён режим `adsterra`. Коды блоков вставлены **статически** в `index.html` — это важно, потому что скрипты Adsterra формата `iframe` используют глобальный `atOptions` и `document.write`, и их нельзя безопасно вставлять динамически после загрузки страницы.

Размещение:

| Место | Формат | Unit | Key |
| --- | --- | --- | --- |
| Шапка | Banner 728x90 | `728x90_1` | `97564551c7f6041b767137fb4d5a5125` |
| Сайдбар | Banner 300x250 | `300x250_1` | `decd2bd36276950022ef50d9d8582986` |
| Панель сборки | Banner 320x50 | `320x50_1` | `987b86fdf7f0c07c8962a876198e30e8` |
| Подвал | Native Banner | `NativeBanner_1` | `bfeefa9aee8f6670a3e5705bb8bf9305` |

Попандеры и Social Bar **не включены** — только баннеры и нативная реклама. Динамические мини-слоты в ленте (`feed`) в этом режиме скрываются через `ads.js`, чтобы не дублировать рекламу.

Настройки лежат в `ads.js`:

```js
const CONFIG = {
  mode: 'adsterra',  // 'adsterra' | 'yandex' | 'demo' | 'adsense' | 'custom'
  adsterra: {
    header: { key: '97564551c7f6041b767137fb4d5a5125', width: 728, height: 90 },
    sidebar: { key: 'decd2bd36276950022ef50d9d8582986', width: 300, height: 250 },
    footerMini: { key: '987b86fdf7f0c07c8962a876198e30e8', width: 320, height: 50 },
    native: { key: 'bfeefa9aee8f6670a3e5705bb8bf9305', container: 'container-bfeefa9aee8f6670a3e5705bb8bf9305' }
  }
};
```

### Демо-режим

`mode: 'demo'` — локальные баннеры, ротация раз в 9 секунд. Ничего не загружается из сети, можно показывать без реального рекламного аккаунта.

### Другие режимы

- `mode: 'adsense'` — вставь свой `adsenseClient` и ID блоков в `CONFIG.slots`. Google AdSense недоступен для выплат в РФ, поэтому режим оставлен для совместимости.
- `mode: 'custom'` — заполни `customHtml`, например:

```js
customHtml: {
  header: '<a href="https://example.com"><img src="banner.png" alt=""></a>',
  footer: '<div>...готовый HTML/JS от рекламной сети...</div>'
}
```

- `mode: 'yandex'` — старый вариант с AutoPlacement (`page-id 20496693`). Сайт был отклонён Яндексом из-за менее 100 посетителей в неделю, поэтому режим не используется.

## Структура

- `index.html` — разметка и статические рекламные блоки
- `styles.css` — стили, адаптив под планшеты/телефоны
- `data.js` — каталог компонентов
- `images.js` — генератор изображений товаров
- `app.js` — логика каталога, фильтров, проверки совместимости и перехода в магазины
- `ads.js` — рекламный слой и настройки рекламы

## Запуск локально (по желанию)

Можно просто открыть `index.html` двойным кликом. Если нужен HTTP-сервер:

```
python -m http.server 8000
```

затем `http://localhost:8000`.
